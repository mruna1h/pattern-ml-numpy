# pattern-ml-numpy

Classical machine learning, dimensionality reduction, and neural network algorithms implemented from scratch in pure **NumPy**, verified against `scikit-learn`.

## Roadmap & Modules
- [ ] Gaussian Naive Bayes & Maximum Likelihood Estimation (MLE)
- [ ] Parzen Window Density Estimator & Vectorized k-NN
- [ ] K-Means & Gaussian Mixture Models (EM)
- [ ] PCA & Linear Discriminant Analysis (LDA)
- [ ] 2-Layer MLP with Manual Backpropagation & Numerical Gradient Checking
